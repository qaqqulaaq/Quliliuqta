Quliliuqta is a card game developed by the Iñupiaq education department of the North Slope Borough school district. This is an electronic 
version of the game, developed for Android and Windows in Gamemaker.

The purpose of Quliliuqta is to find cards that add up to 10. This version of the game also allows the user to set the goal to 5 (Tallimaliuqta)
or 20 (Iñuiññaliuqta). The purpose of this game is to help develop an understanding of the Kaktovik numeral system and vocabulary for numbers
in Iñupiaq. Four dialects are available in the settings.

Game controller support for up to four controllers is available in the Windows release. This feature has not been tested thoroughly as of yet.
